TREEJAR × NOOR Инструкция для владельца Zoho

Виктор, необходимо восстановить доступ Noor к Zoho

Потребуется создать два временных кода: один для Zoho CRM и один для Zoho Inventory. Все дальнейшие технические действия выполнит наша команда.

2
Что нужно передать нам

Два временных кода с пометками «CRM» и «Inventory». Пароль от Zoho и постоянные ключи передавать не нужно.

Перед началом

  • Войдите под владельцем Zoho One с доступом к CRM и Inventory Treejar.
  • Откройте api-console.zoho.com.
  • Используйте уже созданные приложения типа Self Client.

Код для Zoho CRM

1

Откройте Self Client для CRM

Если приложений несколько, выберите то, которое используется для интеграции Noor с CRM.

2

Перейдите во вкладку Generate Code

Вставьте scopes из блока ниже без изменений.

CRM scopes
ZohoCRM.modules.contacts.READ,ZohoCRM.modules.contacts.CREATE,ZohoCRM.modules.contacts.UPDATE,ZohoCRM.modules.deals.READ,ZohoCRM.modules.deals.CREATE,ZohoCRM.modules.deals.UPDATE,ZohoCRM.coql.READ,ZohoCRM.modules.notes.READ,ZohoCRM.modules.notes.CREATE,ZohoCRM.settings.modules.READ
3

Создайте временный код

Выберите максимальный доступный срок действия. В описании можно указать Noor CRM integration.

4

Скопируйте код

Если Zoho попросит выбрать приложение или организацию, выберите Treejar CRM. Сохраните код с пометкой CRM.

Код для Zoho Inventory

1

Откройте Self Client для Inventory

Выберите приложение, которое используется для интеграции Noor с Zoho Inventory.

2

Перейдите во вкладку Generate Code

Вставьте scopes из блока ниже без изменений.

Inventory scopes
ZohoInventory.items.READ,ZohoInventory.items.CREATE,ZohoInventory.items.UPDATE,ZohoInventory.salesorders.READ,ZohoInventory.salesorders.CREATE,ZohoInventory.contacts.READ,ZohoInventory.contacts.CREATE,ZohoInventory.settings.READ
3

Создайте временный код

Выберите максимальный доступный срок действия. В описании можно указать Noor Inventory integration.

4

Скопируйте код

Если появится выбор организации, выберите организацию Treejar в Zoho Inventory. Сохраните код с пометкой Inventory.

Почему код временный? Он нужен только для безопасного получения постоянного refresh token. Сам refresh token после обмена не ограничен выбранными минутами.

Передайте нам два кода

Отправьте их сразу после создания через согласованный защищённый канал. Формат сообщения:

CRM: временный код
Inventory: временный код

Важно

  • Не отправляйте пароль от Zoho.
  • Не отправляйте Client Secret или другие постоянные ключи.
  • Не публикуйте временные коды в общем чате.
  • Не создавайте много кодов подряд: достаточно по одному для CRM и Inventory.
Если нужный Self Client не найден: сделайте скриншот списка приложений без открытых Client Secret и передайте его нашей команде. Мы подскажем, какое приложение выбрать.
