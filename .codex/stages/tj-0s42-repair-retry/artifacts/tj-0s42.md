# Summary

A failed repair call now says what failed. `classify_repair_failure` separates
a transport failure from an answer the schema rejected from a fault of ours,
and the exception class travels on the trace. A failing call is retried once
before the customer loses the reply; both attempts are counted because both
are paid. The per-call timeout was halved in the same change, so two attempts
fit inside the budget one attempt already had.

# Scope / Routing

Root-owned. Opened because the owner questioned the premise of the round's
finding: GLM is a stable model, so `provider_unavailable` was suspicious. It
was — nothing had established it. Every exception was collapsed into that one
label at two call sites.

# The likely second bug, stated as a hypothesis

GLM 5.2 advertises `reasoning` and `reasoning_effort`, and reasoning tokens
are drawn from the same `max_tokens` as the answer. The path allowed 800
tokens for a whole rewritten reply plus a rationale of up to a thousand
characters, and only one model id in the codebase had reasoning explicitly
disabled. A starved structured answer fails, and until this change that
failure was recorded as the provider being down.

Reasoning is now disabled for this path and the budget is 1200 tokens. **This
is not proved.** The stored evidence cannot distinguish the causes, which was
the defect. The next occurrence will name itself, because the class is on the
trace.

# Verification

The protected replay is byte-identical, so nothing in the deterministic chain
moved. The retry is bounded at two and asserted to be bounded, because the
customer is waiting on this call.

# Delivery / Cleanup

One local commit on `main`. No paid call was made in this stage. No push,
deploy, live mutation, model configuration change, or real-user message.

# Risks / Follow-ups / Explicit Defers

No defer. Two limits stated rather than hidden: the reasoning diagnosis is
unconfirmed until the path fires again or a live call is authorised, and a
retry doubles the worst-case spend of a flagged turn, which is why the cap
counts attempts rather than flags.
